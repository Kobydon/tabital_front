# Put the original Tabital Pay logo files here

Save the logo files in this folder with exactly these names, then tell the developer.

| File | What it is |
|---|---|
| `logo.svg` or `logo.png` | The **full logo**: the mark plus the "Tabital Pay" wordmark, side by side (or stacked) |
| `mark.svg` or `mark.png` | The **mark alone** (the square symbol, no text) |

**Best:** SVG files (vector), exported from the original design file (Illustrator, Figma, Canva, CorelDRAW...).

**If you don't have SVG:** PNG files, at least **1024 px** on the long side, on a **transparent background** (no white or coloured box behind the logo).

Tips:
- Send the original colours. The app makes the version for dark (navy) backgrounds itself.
- Leave some space between the mark and the words, so the mark can be cut out if `mark.*` is missing.
- If you only have one file, name it `logo.png` (or `logo.svg`). Two files are better.
- Don't send screenshots or images saved from the website: they are too small and may be compressed.
